Настройка базы данных

Чаты, посты, подарки, реакции, поддержка и админка работают, только если в Supabase выполнен этот код. Его можно запускать повторно — данные не пропадут.

1 Скопируй код

Нажми кнопку — весь код скопируется сам. Ничего выделять не нужно.

2 Вставь и запусти в Supabase

  1. Открой supabase.com → свой проект → слева SQL Editor.
  2. Нажми New query (или +), кликни в пустое поле.
  3. Нажми Ctrl+V — появится очень длинный код (около 2000 строк).
  4. Нажми зелёную кнопку Run. Если спросит про «destructive operation» — нажми Run this query.
  5. Внизу должно быть Success. No rows returned.

Если вместо Success красная ошибка — пришли скриншот.

3 Проверь

Войди на сайт (если ещё не вошёл) и нажми «Проверить». Все строки должны стать зелёными.
