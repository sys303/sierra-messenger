# Sierra Messenger — этап 1

Что уже работает:
- регистрация с ником, именем, почтой и паролем (проверка ника «занят/свободен» на лету, индикатор надёжности пароля);
- **6-значный код подтверждения приходит на настоящую почту**, ввод кода, повторная отправка с таймером;
- вход по почте и паролю;
- профиль: аватарка (загрузка своей фотки), имя, ник, «о себе», редактирование;
- просмотр чужих профилей: `profile.html?u=ник`;
- выход из аккаунта.

---

## Шаг 1. Supabase (база данных и аккаунты)

1. Зайди на **supabase.com** → Start your project → войди через GitHub или почту.
2. **New project**: название `sierra-messenger`, придумай пароль базы (сохрани его), регион — ближайший (например, Central EU).
3. Подожди 1–2 минуты, пока проект создаётся.
4. Слева открой **SQL Editor** → New query → вставь весь файл `supabase/schema.sql` → **Run**. Должно быть «Success».
5. Открой **Project Settings → API** (или кнопку **Connect** вверху) и скопируй:
   - **Project URL**
   - **anon / publishable key**
6. Вставь их в файл `js/config.js` вместо `ВСТАВЬ_СЮДА_...`.

> anon key можно хранить в коде сайта — он публичный и защищён правилами в базе. А вот **service_role key никуда не вставляй**.

## Шаг 2. Включи код вместо ссылки в письме

1. **Authentication → Sign In / Providers → Email**: проверь, что включено **Confirm email**.
2. **Authentication → Emails → Templates → Confirm signup**:
   - Subject: `Твой код для Sierra Messenger: {{ .Token }}`
   - Body: вставь содержимое файла `supabase/email-confirm-signup.html`
   - Save.
3. Длина кода должна быть **6 цифр** (настройка Email OTP Length). Если там другое число — поменяй на 6 или измени `CODE_LENGTH` в `js/config.js`.

На этом этапе письма уже можно проверить, но встроенная почта Supabase — только для тестов: мало писем в час и, скорее всего, только на адреса участников проекта. Для настоящих пользователей — шаг 3.

## Шаг 3. Resend (чтобы письма приходили всем)

1. Зарегистрируйся на **resend.com**.
2. **Domains → Add domain** — добавь свой домен (купить можно на reg.ru, nic.ru и т.п., или через Vercel). Resend покажет DNS-записи — добавь их у регистратора домена и нажми Verify (иногда проверка занимает до часа).
3. **API Keys → Create API key** — скопируй ключ (показывается один раз).
4. В Supabase: **Authentication → Emails → SMTP Settings** → включи **Custom SMTP**:
   - Sender email: `noreply@твой-домен.ru`
   - Sender name: `Sierra Messenger`
   - Host: `smtp.resend.com`
   - Port: `465`
   - Username: `resend`
   - Password: API-ключ из Resend
5. Сохрани. После этого можно поднять лимит писем в **Authentication → Rate Limits**.

## Шаг 4. Публикация на Vercel

1. vercel.com → **Add New → Project** → загрузи папку проекта (или распакованный zip) / подключи GitHub.
2. Framework Preset: **Other**, настройки сборки не нужны — это обычный сайт.
3. После деплоя скопируй адрес сайта и вставь его в Supabase: **Authentication → URL Configuration → Site URL**.

## Проверка

1. Открой сайт → «Зарегистрироваться» → заполни форму.
2. На почту придёт письмо с кодом → введи код → откроется профиль.
3. Нажми на аватарку → загрузи фото. Нажми «Редактировать профиль» → поменяй «О себе».

> Локально двойным кликом по `index.html` сайт не заработает (браузер блокирует модули из файлов). Проверяй после деплоя на Vercel или запусти любой локальный сервер.

## Частые проблемы

| Что видишь | Что сделать |
|---|---|
| Красная плашка «Сайт ещё не подключён» | Вставь ключи в `js/config.js` |
| «Не получилось отправить письмо» | Проверь SMTP (шаг 3): пароль = API-ключ Resend, домен подтверждён |
| Письмо пришло со ссылкой, а не с кодом | Шаг 2.2: в шаблоне должно быть `{{ .Token }}` |
| «Не удалось создать профиль» | Скорее всего, не выполнен `schema.sql` (шаг 1.4) или ник занят |
| Письма нет | Проверь «Спам», подожди минуту и нажми «отправь снова» |

# Этап 2 — Sierra Messenger как мессенджер

## Что добавилось
- **Лента**: посты с фото, лайки, комментарии, удаление своих постов.
- **Чаты в реальном времени**: личные сообщения, фото, ответы на сообщения, редактирование и удаление, «печатает…», «в сети / был(а)», непрочитанные.
- **Группы и каналы**: создание, публичные (с @ссылкой) и закрытые, вступление, админы, исключение участников, аватарка и описание. В каналах пишут только админы.
- **Поиск**: люди по нику и имени, публичные группы и каналы, контакты по **точной** почте или номеру телефона.
- **Контакты**: добавление, список контактов.
- **Телефон в профиле**: привязка номера в Настройках, переключатели «искать меня по почте / телефону».
- **SierCoin**: 100 при регистрации, +25 ежедневный бонус, переводы друзьям, история операций.
- **Подарки**: 10 подарков, лимитированные серии, подписи, отправка прямо из чата.
- **NFT-подарки**: улучшение подарка до уникального NFT со случайной моделью, фоном и узором (у каждого — своя редкость), передача, **маркет** с покупкой и продажей (комиссия 5%).

## Установка этапа 2
1. Supabase → **SQL Editor** → New query → вставь весь файл `supabase/stage2.sql` → **Run**. Должно быть «Success».
2. Загрузи новые файлы сайта на Vercel (как в прошлый раз).
3. Зайди на сайт — после входа откроется приложение (`app.html`).

Все, кто зарегистрировался раньше, автоматически получат кошелёк со 100 SierCoin.

## Важно знать
- SierCoin — **внутренняя валюта**, их нельзя купить за настоящие деньги. Баланс меняется только на сервере, поэтому «накрутить» его из браузера нельзя.
- NFT здесь — это уникальные коллекционные подарки внутри Sierra, а не токены в блокчейне.
- Номер телефона пока **не подтверждается по SMS** (это платно). Поэтому теоретически кто-то может привязать чужой номер. Почта подтверждена кодом, на неё можно полагаться.

## Что дальше
Голосовые сообщения, стикеры, звонки, боты, жалобы и админка, уведомления в браузере.

# Этап 3

- **250 подарков**: 25 анимированных моделей × 10 расцветок (Классика, Рубин, Сапфир, Изумруд, Аметист, Закат, Лёд, Неон, Золото, Космос). Цены от 15 до 10 000 SierCoin, 96 лимитированных.
- **NFT за 25 SierCoin** — сразу при покупке или позже. Каждый NFT получает случайную **модель** (24 вида), **фон** (24) и **символ** (22) с редкостью от «Обычного» до «Легендарного» и **оценку стоимости**.
- **Посты**: лайки, комментарии, пересылка в чаты, ссылка на пост, жалоба.
- **Чаты**: реакции (двойной клик — ❤️), панель эмодзи, пересылка сообщений «как в Telegram».
- **Поддержка**: чат «Поддержка Sierra» у каждого пользователя.
- **Жалобы** на пользователей, сообщения и посты.
- **Админ-панель**: обзор, жалобы с ответами, поддержка, пользователи, бан/разбан, выдача SierCoin.

## Установка
1. Загрузи файлы на Vercel.
2. Открой `/setup.html` → «Скопировать код» → Supabase → SQL Editor → вставить → Run.
3. Назначь администратора (код — в инструкции в чате, в файлы сайта он специально не добавлен).

# Этап 4
- **Маркет юзернеймов** (Подарки → @ Юзернеймы): разделы 3 / 4 / 5 / 6 символов. Выставляют только пользователи, за свою цену, комиссия 5%.
- **Мои юзернеймы**: до 10 бесплатных, основной + «also @…» в профиле, продать, снять, освободить, сделать основным.
- Метки **Legend / Rare / Limited**, счётчик «Осталось» обновляется у всех в реальном времени.
- **Смена пароля** в Настройках.
- **Админка → Подарки**: выдать любой подарок себе или другим (можно сразу NFT).

Установка: загрузить файлы на Vercel → `/setup.html` → «Скопировать код» → Supabase SQL Editor → Run.
